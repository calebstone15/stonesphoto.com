EAA - ERPL Analysis App

The ERPL Analysis App is a comprehensive data analysis tool developed for the Embry-Riddle Propulsion Laboratory. This web-based application streamlines the process of analyzing hotfire test data, calculating key performance metrics, and visualizing results.

Key Features:

  • Hotfire Data Analysis with interactive plotting
  • CdA (Discharge Coefficient × Area) Calculator
  • Draco Pressure Loss Calculator
  • Mass flow rate calculations from venturi measurements
  • Custom plot builder with multiple data series support

Built using modern web technologies, the app provides a responsive interface that works seamlessly on both desktop and mobile devices.
