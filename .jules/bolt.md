## 2024-03-02 - [Parse Number Optimization]
**Learning:** `Utils.parseNumber` uses `String(value).trim().replace(/,/g, '')` which allocates multiple intermediate strings and performs regex replacement on every single value, even though most CSV numbers don't contain commas and are already strings. Additionally, the native `Number()` constructor evaluates whitespace-only strings (e.g., `"  "`) to `0`, while `parseFloat` treats them as `NaN`. Care must be taken not to regress behavior.
**Action:** Optimize `Utils.parseNumber` by explicitly trimming and checking for empty string, then using `Number(value)` for strings without commas (`indexOf(',') === -1`) before falling back to `parseFloat(value.replace(/,/g, ''))`.
